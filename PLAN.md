## Decisions (do not reopen)

- Proxy network IPv6 (FOLLOW-UPS bullet 1): `remote-up` always creates the `proxy` network with `--ipv6`. This needs Docker 27 or later, which auto-assigns an IPv6 subnet and has ip6tables on by default; on older daemons the create fails, and the recipe's error output and the docs say to create the network by hand with `--ipv6 --subnet <ipv6-cidr>`. No host detection (no "only when the host has global IPv6" branch).
- The local `_network` recipe (`justfile:8`) stays unchanged: local hosts never run `just firewall`.
- Existing servers whose `proxy` network was created without IPv6 still need the documented manual recreate; `remote-up` keeps an existing network as is (no automatic teardown/recreate).
- Docs (FOLLOW-UPS bullet 2): the built firewall material moves into its own `## Firewall` section of `docs/architecture.md`; `## Server bootstrap (planned)` keeps only the planned-script paragraph and links to the new section.
